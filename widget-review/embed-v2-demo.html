Kurs-Widget für socialy.club

Ein schlankes Single-Course-Widget zum Einbetten auf deiner Kursdetailseite. Zeigt die nächsten Termine, Belegung live, direkt buchbar.

Schritt 1
Kurs auswählen
Activity-ID finden: Im Provider-Dashboard → Kurse → Kurs öffnen → URL enthält die ID. Oder später via "Widget einbetten"-Button direkt am Kurs.
Schritt 2
Embed-Code kopieren
Optional · Auto-Höhe
Mit diesem Script passt sich die iframe-Höhe automatisch dem Inhalt an — ideal wenn die Kursliste mal länger, mal kürzer ist.
Alternative · Auto-Liste
Alle Kurse eines Providers auf einmal
Schritt 3
Auf socialy.club einbauen
1Im Decap CMS auf socialy.club die Kursdetail-Seite öffnen, an der Stelle wo der Widget rein soll einen HTML-Block einfügen.
2Den iframe-Snippet oben einfügen. Activity-ID jedes Mal an den jeweiligen Kurs anpassen.
3Optional: das Resize-Script einmalig in die Socialy-Site-Basis einbauen — dann funktioniert's automatisch für alle Kurse.
4Deployen → Live-Preview auf socialy.club testen → Kursleiter:innen promoten.
