Was ist eine PWA?
„Progressive Web App" — eine Web-Seite die sich wie eine App verhält. Du sparst dir den Download (3 Sek statt 30 MB), bekommst ein Icon auf'm Home-Screen und kannst sie offline öffnen. Ohne Apple- oder Google-Konto.
