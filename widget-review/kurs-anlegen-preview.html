V2 Design Preview

„Neuer Kurs"-Modal

Kompletter Kurs-Creator im UKC-Brandbook (Linen / Sienna / Brown / Temptress · Barlow + Fraunces + Inter). Klick den Button und probier's aus — KI-Beschreibung, Zeitplan dynamisch erweitern, Preismodell mit zweiter Option, Farbwahl.

Zurück zum Dashboard
1Mit-KI-generieren-Button bei der Beschreibung — wählt je nach Kategorie einen passenden Vorlagen-Text. Der echte Stripe-API-Aufruf käme an die Stelle wo aktuell ein Demo-Loader läuft.
2Zeitplan mit „+ Weiteren Tag hinzufügen" für mehrere Wochentage gleichzeitig (z. B. Mo + Mi + Fr).
3Zweite Preisoption per Checkbox sichtbar — z. B. Drop-in zusätzlich zum 8er-Paket.
4Kalenderfarbe ist mit den Brand-Kategorien gemappt (Eltern-Kind / Bewegung / Musik / Kreativ / Tanz / Sprache / Natur / Sonstige) — die Wahl bestimmt direkt wie der Termin im Kalender erscheint.
5Validierung auf Kursname + Preis. Bei Fehler wackelt das Feld kurz und es kommt ein Toast.
6Auto-Hook: Jeder Button mit Text „Neuer Kurs" / „Kurs anlegen" auf den V2-Preview-Seiten öffnet ab jetzt diesen Modal — auch in der Sidebar, Topbar, Empty-State-CTAs.
