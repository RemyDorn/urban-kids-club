Migration 006 · Parent Federation Schema
Vollständig ansehen → 
-- Global parent identity (one row per real human)
CREATE TABLE parents (
  id              UUID PRIMARY KEY,
  email           CITEXT NOT NULL UNIQUE,           -- case-insensitive global anchor
  display_name    TEXT,
  phone           TEXT,
  ...
);

-- M:N — same parent can be linked to multiple providers
CREATE TABLE parent_provider_links (
  parent_id                 UUID REFERENCES parents(id),
  provider_id               UUID REFERENCES providers(id),
  share_with_other_providers BOOLEAN DEFAULT FALSE,  -- Phase-2 opt-in
  marketing_consent          BOOLEAN DEFAULT FALSE,
  UNIQUE (parent_id, provider_id)
);

-- Provider sees only their own parents (RLS)
CREATE POLICY parents_provider_scope ON parents
  FOR SELECT USING (
    EXISTS (SELECT 1 FROM parent_provider_links ppl
            WHERE ppl.parent_id = parents.id
              AND ppl.provider_id = current_setting('app.current_provider_id')::UUID)
  );

Roll-out Plan

01
PWA-Schicht live jetzt
Manifest, Service Worker, Install-Banner, Provider-Branding-Registry. Eltern können /portal/socialy aufs Handy installieren. Account-System läuft noch auf bestehendem customers-Schema.
02
Federation-Schema deployen Q2
Migration 006 anwenden, Backfill von customers → parents + parent_provider_links. Backend-API-Layer auf parent_id umstellen, RLS aktivieren. Verhalten unverändert für Eltern.
03
Magic-Link-Auth Q2
Eltern melden sich mit Email an. Erste Buchung bei zweitem Provider erkennt Account → Mama bestätigt „verbinden", parent_provider_links bekommt zweiten Eintrag. White-Label bleibt erhalten.
04
Push-Notifications Q3
VAPID-Keys, Subscription-API, Server-Komponente für Buchungs-Bestätigungen, Wartelisten-Matches, Krankmeldungs-Antworten. Opt-in pro Provider.
05
Kids Club Master-App (B2C-Pivot) Q4+
/portal/ukc aktivieren als Master-View — zeigt alle Provider an die die Mama opt-in geteilt hat. Discovery-Layer für neue Studios in der Stadt. Zeitpunkt: wenn 5+ Provider live sind und der Pull-Effekt da ist.
